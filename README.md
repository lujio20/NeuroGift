> ## Overview
>
> NeuroGift is an intelligent gift recommendation platform that leverages behavioral AI and user profiling to deliver hyper-personalized gift suggestions. The system combines two custom-trained AI models with a responsive web interface to create a seamless gift discovery experience.
>
